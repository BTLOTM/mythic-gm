Mythic GME 2 Solo RPG Tool

A web-based companion tool for Mythic Game Master Emulator 2nd Edition—the definitive system for running solo tabletop RPG adventures without a Game Master.

About Mythic GME 2
Mythic Game Master Emulator 2nd Edition is a complete system for running solo RPG adventures. It provides:

Fate Question mechanics for resolving narrative uncertainties
Scene structure and pacing guidance
Random event generation with meaningful keywords
Integration with any tabletop RPG system

This tool implements the core Scene Transition, Fate Question, and Random Event systems from the rulebook.
**Get the full rulebook**: Visit [Word Mill Games](https://www.wordmillgames.com/)
